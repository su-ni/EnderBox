## 修完：像素转角被裁（2px 横向溢出）
- 现象：整合包详情页 / 整合包市场页 `main.scrollWidth = clientWidth + 2`（1440 与 520 都有，其它 12 个页面干净）。
- 真凶：`.panel::before/::after` 是 6×6 像素转角标，`left/right:-4px` 故意探出面板外缘 2px。
  页面内容贴住 `main` 左右缘时（PageFrame 直出页 = 全屏无内边距），转角被 `.main{overflow:hidden auto}` 裁掉 —— 右侧竖笔画只剩 1px、左角完整，一残一整。
- 修法（不改设计稿转角几何）：
  - `ProjectShell` 版心 `mx-auto max-w-[1240px]` → 加 `px-1`（4px 侧衬，给转角让位）；
  - `PageFrame` 新增可选 `pad` prop（`<main class="main anim-fade px-1">`），整合包市场 `<PageFrame pad>` 用上。
  - 新建向导自带 `px-4`、标准页走 `.content`（30px gutter）——都不用动。
- 验证：两页 @1440/@520 全部 `mainSW==mainCW`；面板右缘从贴边（1421）收到 1417，留 4px 余量。

## 排查手法（可复用，伪元素类溢出）
rect 扫描（元素盒）、Range 文本扫描、伪元素枚举**三路都抓不到**时：
`scrollWidth-clientWidth` 的链条会一路指到 panel，但**把 panel 全体子元素 display:none 后 delta 仍不归零**
→ 说明溢出不属于任何真实元素 → 直接去 CSS 里找该元素的 `::before/::after` 负偏移。
（同理：文本溢出/伪元素都不会被 `getBoundingClientRect` 反映。）

## ⚠ URL 入口坑（探针误判的两次）
- 模组市场 = `?page=plugins&mod=market`；模组详情 = `?page=plugins&mod=market&pm=<id>`。
  只给 `?mod=market` 或 `?pm=<id>` 会**落到概览页**（`page` 缺省 home），探针会量到概览页并误判成"没渲染 / 干净"。
- `?pk=<id>`（整合包详情）、`?view=market`（整合包市场）、`?dl=1`（下载台账）是全局 view，可单独用。
- 结论：探针 `waitFor` 一直不成立时，先怀疑 URL 打错了，别怀疑产品。

## 修完：详情页切 tab 整页横跳（用户「介绍和下载页面需要固定相同的宽」）
- 实测 @1920：介绍页容器 1240、下载页 1140（每边跳 50px）。
- 根因（很通用，记牢）：**flex 列容器里，子项一旦有 `margin:0 auto`（mx-auto）就不再被拉伸**，
  改成按内容收缩（fit-content）再被 `max-width` 截断 → 宽度随内容变。
  main / .content / 向导容器都是 `display:flex; flex-direction:column`，所以 `mx-auto max-w-*` 全都中招。
- 修法：给容器一个**确定宽度** `w-full`（`mx-auto w-full max-w-[1600px] px-1`）。向导 `.wz-shell` 同理补 `width:100%`。
- 顺带把版心 1240 → **1600**（用户「左右这么多的空间不用」）：1920 屏左右留白 204px → 24px。
- 验收：两 tab 容器都是 1600、左缘都是 277。
