## ⚠ 已经踩过的坑（别再犯）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| 改设计稿源文件 | 两列不等高 | **改实现，不许改设计稿** |
| `data-page` 照抄 `overview` | 规则一条不生效 | 本项目那页的 key 是 **`home`** |
| 组件自带一层 `<section>` | `> .grid-2` 永远匹配不到 | 搬之前**剥掉最外层 section** |
| `flex: 1 1 auto` 填满高度 | 内容被压坏/溢出被裁 | 一律 `flex: 1 0 auto`（**只长不缩**） |
| 绕过 PageFrame 的视图 | 底部被健康条压住 | 自己加 `pb-[calc(var(--hud-h)+10px)]` |
| 改 CSS 后毫无变化 | 先怀疑选择器没匹配上，**再**怀疑 vite 缓存 | 清 `node_modules/.vite` + 重启 |
| 拿标称窗口高当视口高 | 判定失真 | 探针读 `vh`（1440×900 实际只有 804 高） |
| 只看 `.frow` 的 CSS 默认 5 列 | 把文件行改成了表格式 | **inline 覆盖后的渲染呈现才是设计稿**（files 块每行都是 3 列），别拿 CSS 默认值当意图 |
| 长描述数据撑歪行高 | Konkrete 行 131px | 列表描述类限一行（`.rsub.one-line`）+ `title` 放全文 |
