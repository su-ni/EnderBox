设计规范 · token 总表

这是整套 UI 的唯一事实来源。后续铺开其余页面、以及把 React 前端改成这套视觉时，颜色、字号、间距、浮雕、动效曲线 一律从这里取值，不要临时新增中间值 —— 字号一多、颜色一散，页面立刻就散了。 风格定位：像素 / 游戏；美学方向：「深岩工作台」（深石板地质层 + 钻石青主色 + 铜橙点缀，一切容器用 MC 背包 GUI 的硬浮雕）。

04

组件状态

交互元素必须齐备 default / hover / active / focus / disabled。焦点环统一 2px 青色 + 2px 偏移。

按钮

active 时整体下沉 1px 并翻转浮雕方向；主操作与启动按钮 hover 时有一次斜向附魔闪光。

输入 / 开关 / 复选
OP 4白名单已封禁普通
数据展示：方块刻度条 + 火花线

水位数自动变色：<70 绿 / 70~90 黄 / ≥90 红；「越满越好」的指标（运行时长）由调用方强制指定颜色。

状态徽记与点
运行中 已停止 LIVE 已连接 重连中 已断开

运行中的态一律带「呼吸 + 外扩环」两层动效，静止的态不带 —— 一眼就能分清「活的」和「停的」。

06

间距 · 圆角 · 布局

项值说明
间距基数4px只用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40，禁止 13px、17px 这类随手值
圆角0像素风不做圆角；需要「柔」的地方用留白，不是圆角
阴影4px 4px 0 rgba(0,0,0,.45)只有硬投影一种，不叠加柔和阴影
侧栏宽252px桌面固定；≤1080px 收成抽屉
内容最大宽1500px居中；页面本身不滚动，只有主列滚动
断点1180 / 1080 / 900 / 8601180 收分栏、1080 收侧栏、900 收工具条、860 收表格列与 HUD
07

动效

原则：一条有导演感的入场编排 > 一堆零散微交互。全部 ease-out，禁止回弹曲线（像素配回弹显廉价）。

参数值用在哪
时长fast 120ms / 常规 200ms / 入场 320ms状态反馈 / 过渡 / 入场
曲线cubic-bezier(.16,.84,.44,1)唯一曲线，全站统一
入场编排.reveal + --rd 递进延迟每屏首次进入时按区块顺序上浮，延迟 0.02s~0.32s 递进
背景大气层像素尘 float / 网格 drift 90s / 光晕 breathe让页面「活着」，但不抢内容
实时律动呼吸 breathe / 外扩环 ring / 经验条 xpstripe只给「运行中 / LIVE」这类活体状态
数据刷新刻度条逐格点亮 46ms/格 / 数字滚动 880ms / 读数 bump 闪光指标带
交互细节附魔闪光 glint/sweep / 像素四角点亮 / 按钮下沉 1px按钮、面板、页签
无障碍prefers-reduced-motion + body.no-anim系统减弱动态时全关；设计稿工具条上也能一键暂停
08

App Shell（唯一骨架）

所有页面共用同一个外壳，切换页面只换主内容槽 —— 导航永远不动。

层结构职责
顶栏.topbar草/土材质条 + 品牌 + 连接状态 + 全局动作（刷新 / 新建）
侧栏aside.side世界列表（MC 物品槽 + 状态点）+ 新建 / 导入；底部固定不随内容滚
身份头.world-head「我在操作谁」：名称 + 状态徽记 + 端口/内存/PID + 启停动作
页签.tabbar .tabMC 物品槽页签，选中态青底 + 下三角指针
内容.content .page每屏一块；.page.on 才显示
HUD.hud生命（体检健康度）+ 经验条（实时活跃度/TPS）+ F3 式信息

隐喻对照：爱心 = 启动前体检健康度；经验条 = 服务器活跃度；物品槽 = 页签与列表；背包浮雕 = 一切容器。中文不套像素字体，像素味由图标 / 数字 / 边框 / 材质承担 —— 这是「极致像素」与「可读性」之间的平衡点。

09

行列表与面板头

插件模组 / 备份还原 / 计划任务三屏共用同一套行列表；面板头承担「统计 + 搜索 + 筛选 + 动作」四件事。这一节是补齐后四屏时新增的。

组件结构职责与约束
行列表.rlist · .rrow四列：32px 图标槽 · 主体 · 行尾机器信息 · 操作。行间只有 1px 发丝线，首行不加线
行主体.rtitle · .rsub标题 13.5px/600 + 徽记；副标题 12.5px 灰。一行放不下就换行，不省略号截断
行尾信息.rmeta文件名 · 大小，等宽字体。860px 以下隐藏 —— 手机档把宽度让给标题和操作
行状态.rrow.dep · .off缺前置 = 左侧 3px 黄条 + 淡黄底；已禁用 = 图标去色压暗，但开关本身不压暗（那一下正是用户要点的地方）
键值明细.pol-foot策略/任务的「上次 · 下次 · 触发方式」，键走像素字体小号，值走等宽，640px 以下改为上下堆叠
面板头.con-head标题 + 统计 + 搜索 + 筛选芯片 + 动作；860px 以下整条换行，筛选组独占一行
面板脚注.con-foot一句「你该知道、但不必天天看」的话；不塞实现细节
动作流水线.crash-step 复用计划任务的「有顺序动作」直接复用崩溃诊断的三步式编号，末行加 .add 变虚线

筛选芯片（.chipf）默认单选，容器加 data-multi 变多选 —— 备份的「触发方式」两种可以一起开。芯片一律 white-space:nowrap：它是按钮，不该折行。
⚠ 行尾加 .rmeta 这类「机器信息」时记住：它排在标题右侧而不是标题下面，否则中间会留一条上千像素的空档，眼睛要从名字一路跨到最右边。
