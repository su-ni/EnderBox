监听地址

决定谁能打开这个面板。默认只允许本机，改了要重启面板才生效。

只允许本机访问

监听 127.0.0.1:23333。最安全，手机上想看就走你自己的内网穿透。

允许局域网访问

监听 0.0.0.0:23333。同一 WiFi 下手机直接访问 192.168.1.20:23333。

可用
注意别跟服务器的 25565 撞上，一般不会。
这台机器在 WiFi 里的地址，会随路由器重新分配而变。
锁 10 分钟。家用环境开着比较安心。

Java 运行时

开服器会按你选的服务端自动挑 Java —— 1.16 及更早要 8，1.17 到 1.20.4 要 17，1.20.5 往后要 21。缺的它自己下，你也可以提前放好。

版本来源路径用于操作
Java 21.0.5 默认系统已安装 F:\Java\java 211.20.5 及更新 打开目录 · 重新检测
Java 17.0.9自动下载 runtimes\jdk-17.0.91.17 – 1.20.4 设为默认 · 打开目录
Java 8未安装 runtimes\jdk-8u3921.16.5 及更早
系统里已装的 Java 会被优先复用，不重复占用空间

自动下载设置

只影响「本机没有、需要临时补一个」的情况。

不确定就用 Temurin，兼容性最好。
失败会自动换下一个源重试。
别放 C 盘。一个 JDK 约 200 MB。

下载源

国内直连官方源经常龟速甚至失败，所以每个环节都能单独换源。右边数字是刚才实测的延迟，不是猜的。

服务端文件

负责下 Paper / Fabric / Forge 这些十几到几十 MB 的 jar。

12 msBMCLAPI 镜像（推荐）

国内镜像，速度稳定。文件与官方一致，带 SHA256 校验。

340 ms官方源

最权威，但国内直连偏慢。选了也能用，就是得多等会儿。

插件与模组

Modrinth 和 CurseForge 的元数据与文件走这条通道。两个来源任何一个不通，市场页会明确告诉你缺了哪边。

88 ms走本机网络直连

如果你自己挂了代理，选这个最省事。

连接失败内置加速通道

需要能访问加速节点。当前不通，可能是网络策略挡住了。

网络参数

开太大容易被限速甚至封 IP，4 够用。
单位秒。超时自动换下一个源重试。
留空表示不用。只影响下载，不影响面板访问。

守护与启动

管的是「电脑重启之后」和「服务器崩了之后」该怎么办。默认值对家用场景已经够稳。

开机自动启动 ServerBox

登录 Windows 后自动把守护进程挂起来，不开完整窗口，直接进托盘。

实例崩溃后自动重启

进程异常退出时自动重开。崩之前最后 200 行日志会单独存档，方便查原因。

重启前广播提醒在线玩家

自动重启会打断在线的玩家。开着更礼貌，代价是重开晚 30 秒。

阈值

超过就停下并标红，不再无限重试耗你 CPU。
发 stop 后等这么久，还没退就强杀进程树。
保留天数，到点自动清。
